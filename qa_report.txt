Learnings from Fixing CORS allow_credentials vulnerability:
1. When fixing security defaults in middleware (like CORS), introduce an explicit configuration flag (e.g., BACKEND_CORS_ALLOW_CREDENTIALS) with a secure default (False).
2. Do not blindly fallback to insecure options (like True) just because an origin list exists.
3. Clean up any temporary patch files (.py scripts used for regex replacement) and binary artifacts (.coverage) created during the fix process before submitting the PR to avoid codebase pollution.
